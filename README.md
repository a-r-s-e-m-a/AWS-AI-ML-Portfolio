## About This Portfolio

Welcome to my AWS AI & ML Portfolio!

This repository documents my learning journey throughout the AWS Student Builder Group program. It brings together weekly assignments and practical projects focused on programming, data processing, artificial intelligence, machine learning, and related technologies.

My goal is to develop practical technical skills, strengthen my problem-solving abilities, and build a solid understanding of the concepts through hands-on implementation.

## Technology Stack

The technologies used will grow as I progress through the program.

- **Programming:** Python
- **Data Processing:** NumPy, Pandas
- **Development Environment:** Jupyter Notebook, Google Colab, VS Code
- **Version Control:** Git and GitHub
- **Cloud & AI:** AWS and relevant AI/ML tools as introduced throughout the program
